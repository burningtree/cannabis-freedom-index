Before Burkina Faso had a drug code, it punished drugs through its health code. The
Public Health Code adopted by parliament on 19 May 1994 made holding narcotics without a
legitimate reason punishable by six days to six months in prison, a fine, or
both.[@1]

Group use drew heavier treatment: using drugs in a group, or helping someone else use
them, carried one to five years in prison, a fine, or both, with doubled penalties for
illicit growing or manufacture.[@1] The health-code offences already paired repression
with a medical framing that later codes kept — courts could steer dependent users
toward treatment, a route the 2018 code still offers and Mainline still finds rarely
used.

The 1994 penalties preceded the 1996 Penal Code and the more detailed drug code adopted
in 1999, which distinguished small personal growing from ordinary production and set
the minimum-fine architecture judges still work within.[@1]
