Public Law 21-08 restored the 1997 amendments to sections 1141 and 1147
that the 2014 annotated code had omitted.[@1]

It added import and export to section 1141 and created a
fifteen-year/$15,000 tier for large amounts of heroin, cocaine, LSD or
crystal meth; marijuana remained in the five-year/$5,000 tier.[@1]
